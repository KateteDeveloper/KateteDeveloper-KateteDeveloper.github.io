## About

싱글 페이지 구조로, 자기소개부터 기술 스택, 성장 곡선, 프로젝트, 활동 이력, 학술 논문까지 한 번에 볼 수 있도록 구성했습니다.

- **Hero** — 첫 진입 시 초록 커튼이 좌우로 열리는 인트로, 이름 드롭인 애니메이션
- **About** — 소개, 학력, 기술 스택
- **Growth** — GitHub 활동 지표와 실제 역할 변화를 기준으로 그린 성장 곡선
- **Projects** — LinkU · 꾹(GGUK) · 리루티 · FitBuddy · 말뭉치 프로젝트 카드 (실제 앱 화면 + 로고)
- **Activities** — 동아리·학회 활동 타임라인
- **Papers** — 학술 발표 논문(FitBuddy, 말뭉치) PDF 링크

## Stack

- 순수 HTML/CSS/JS (프레임워크 없음)
- 폰트: [Paperlogy](https://noonnu.cc/font_page/1345)
- 컬러: `#006242` 그린 + `#a0f669` 라임 포인트
