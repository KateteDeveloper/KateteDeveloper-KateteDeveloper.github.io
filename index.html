LinkU (링큐)

Play 비공개 테스트 중
2025.07 ~ 진행중

자신에게 중요한 링크를 저장·관리하는 안드로이드 앱. 링크를 저장하면 자동으로 요약·태그를 붙여 정리하고, 사용자 맞춤 추천 링크(큐레이션)를 제공합니다. 다른 앱에서 링크를 복사·공유하면 곧바로 LinkU로 연결되는 원터치 저장을 지원합니다.

프로젝트 성과

  • 앱 전역 API 에러 처리 구조 설계로 화면마다 제각각이던 에러 핸들링을 표준화, ApiError sealed class와 safeApiCall로 통일
  • Compose NavHost 상태 미반영 버그(닉네임 실시간 미갱신) 직접 원인 분석 및 해결
  • Share Intent 공유 기능과 딥링크 기반 화면 라우팅 구현으로 링크 저장 depth 단축

역할 요약

  • 로그인·회원가입, 큐레이션 화면 개발
  • 앱 전역 API 에러 핸들링 구조(ApiError, safeApiCall) 설계
  • Share Intent 공유 기능, 딥링크 라우팅 구현
  • 로그아웃/INACTIVE 계정 복구 API, 토큰 재발급 횟수 제한 로직 구현
  • Compose 상태 관리 버그 직접 분석·해결
